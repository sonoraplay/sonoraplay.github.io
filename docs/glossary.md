# Glossary

| Term | Meaning |
|---|---|
| **Rights holder** | Label, distributor or collecting society that owns the rights to tracks and receives royalties |
| **Royalty** | Money paid to a rights holder for valid plays |
| **Settlement** | The monthly calculation of royalties; each run has a unique settlement ID |
| **Revenue pool** | The money available per country and month to pay royalties (52 % of subscriptions + 45 % of advertising) |
| **Valid play** | A play with at least 30 continuous seconds, within the daily cap |
| **Stream farm** | Fake accounts or bots that play music to inflate royalties |
| **Adjustment** | A play paid in a later month (late offline sync or cleared after fraud review) |
| **Append-only** | Records are only added, never changed or deleted |
| **Billing country** | Country where the account pays; it decides which pool the plays belong to |
| **Playback country** | Country where the play happened; used for territorial exclusions |
| **Churn** | A customer who cancels or does not renew (a plan change is not churn) |
| **Bronze / Silver / Gold** | Data lake layers: raw, clean, ready for settlement |
| **F1–F7** | The seven data sources (catalog, events, subscriptions, contracts, advertising, exchange rates, countries) |
| **RN** | Business rule (*regla de negocio*) |
| **RF / RNF** | Functional / non-functional requirement |
| **CA** | Acceptance criterion (*criterio de aceptación*) |
| **HU** | User story (*historia de usuario*) |
| **EG-nn** | Jira ticket of the project |
| **ADR** | Architecture Decision Record |
| **Q1–Q10** | The ten open questions about the business rules |
| **UTC** | Coordinated Universal Time; the time zone for every day and month |
| **JWT** | Signed token used by rights holders to log in |
| **Terraform** | Tool that creates and destroys the cloud infrastructure from code |
| **Fargate / Spot** | AWS service to run containers without servers; Spot is cheaper but can be interrupted |
| **OIDC** | Lets GitHub Actions access AWS without stored keys |
| **SSM tunnel** | Secure connection to private resources without opening ports |
