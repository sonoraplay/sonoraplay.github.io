# Glosario

| Término | Significado |
|---|---|
| **Titular de derechos** | Sello, distribuidora o sociedad de gestión dueña de los derechos de las pistas, que recibe regalías |
| **Regalía** | Dinero que se paga a un titular por las reproducciones válidas |
| **Liquidación** | El cálculo mensual de las regalías; cada corrida tiene un ID único |
| **Bolsa** | El dinero disponible por país y mes para pagar regalías (52 % de suscripciones + 45 % de publicidad) |
| **Reproducción válida** | Una reproducción con al menos 30 segundos continuos, dentro del tope diario |
| **Granja de reproducciones** | Cuentas falsas o bots que reproducen música para inflar las regalías |
| **Ajuste** | Una reproducción que se paga en un mes posterior (sincronización offline tardía o liberada tras la revisión de fraude) |
| **Append-only** | Los registros solo se agregan; nunca se modifican ni se borran |
| **País de facturación** | País donde paga la cuenta; decide a qué bolsa pertenecen sus reproducciones |
| **País de reproducción** | País donde ocurrió la reproducción; se usa para las exclusiones territoriales |
| **Churn** | Un cliente que cancela o no renueva (un cambio de plan no es churn) |
| **Bronze / Silver / Gold** | Capas del Data Lake: crudo, limpio, listo para liquidar |
| **F1–F7** | Las siete fuentes de datos (catálogo, eventos, suscripciones, contratos, publicidad, tasas de cambio, países) |
| **RN** | Regla de negocio |
| **RF / RNF** | Requisito funcional / no funcional |
| **CA** | Criterio de aceptación |
| **HU** | Historia de usuario |
| **EG-nn** | Tarea de Jira del proyecto |
| **ADR** | Registro de decisión de arquitectura (Architecture Decision Record) |
| **Q1–Q10** | Las diez preguntas abiertas sobre las reglas de negocio |
| **UTC** | Tiempo universal coordinado; la zona horaria de todos los días y meses |
| **JWT** | Token firmado con el que entran los titulares |
| **Terraform** | Herramienta que crea y destruye la infraestructura en la nube desde código |
| **Fargate / Spot** | Servicio de AWS para correr contenedores sin servidores; Spot es más barato pero se puede interrumpir |
| **OIDC** | Permite que GitHub Actions entre a AWS sin llaves guardadas |
| **Túnel SSM** | Conexión segura a recursos privados sin abrir puertos |
